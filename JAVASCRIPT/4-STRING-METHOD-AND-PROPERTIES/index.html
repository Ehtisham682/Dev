String Methods and Properties

Properties

length: it is used to get the number of characters in a string.

Methods

    without arguments

  • toLowerCase(): converts a string to lowercase.
  • toUpperCase(): converts a string to uppercase.
  • trim(): removes whitespace from both ends of a string.
  • trimStart(): removes whitespace from the beginning of a string.
  • trimEnd(): removes whitespace from the end of a string.

    • with arguments

  • includes(): checks if a string contains a specified substring.
  • indexOf(): returns the index of the first occurrence of a specified substring.
  • lastIndexOf(): returns the index of the last occurrence of a specified substring.
  • replace(): replaces a specified substring with another substring.
  • replaceAll(): replaces all occurrences of a specified substring with another substring.
  • concat(): combines two or more strings.
  • padStart(): pads the beginning of a string with another string.
  • padEnd(): pads the end of a string with another string.
  • charAt(): returns the character at a specified index.
  • charCodeAt(): returns the Unicode of the character at a specified index.
  • split(): splits a string into an array of substrings.
